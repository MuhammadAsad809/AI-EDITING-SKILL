# Mobile Phonk Workflow

Use CapCut, Alight Motion, or VN when the project benefits from touch-first speed and social delivery. Create a clean project at the final aspect ratio, import the track first, and mark structural beats before trimming clips. Keep the primary subject on the main track; use named overlay layers for text, masks, and textures.

Build the hook and drop without presets. Add a single speed curve to movement-heavy clips, a short impact pulse at the hero moment, and captions inside safe areas. Preview at full playback speed and at low phone brightness. If the project becomes difficult to review, remove effects rather than lowering editorial standards. Export a review file before the final file and retain original media.
