# [AI TOOL] Assisted Editing Workflow

Use AI tools as modular helpers around a human-directed edit. Tool names and capabilities change; verify the current application before promising a feature.

## Workflow

1. Write the editorial promise, subgenre, song section, and intended shot role.
2. Use transcription, tagging, or beat detection to accelerate organization.
3. Build the clean cut manually or in the target NLE.
4. Generate only missing inserts, backgrounds, textures, or graphic variants.
5. Inspect generated media for continuity and artifacts.
6. Integrate with matched color, grain, motion blur, and sound—not as an ungraded pasted layer.
7. Keep the original and note tool, prompt, settings, and revision.

## Fallbacks

If beat detection is unavailable, mark downbeats manually. If background removal is unstable, use a clean crop or a practical foreground wipe. If generative video changes identity, use a short texture insert or real B-roll. If enhancement creates artifacts, return to the original and use a conservative crop or denoise pass.

## Ethics and rights

Confirm rights for music, source footage, likenesses, logos, and generated outputs. Do not fabricate a real person’s action or imply documentary authenticity without disclosure. Avoid generating dangerous driving instructions or unsafe stunts; editorialize existing footage responsibly.
