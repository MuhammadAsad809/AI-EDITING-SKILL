# Contributing

Add knowledge that makes an AI editor more precise. Prefer a compact rule, a rationale, a counterexample, and a worked application over a feature inventory. Use neutral language and mark version-sensitive software behavior as `verify`.

## Content checklist

- Does the recommendation identify what, when, why, how, strength, and failure mode?
- Does it preserve story and intelligibility?
- Does it distinguish universal editing theory from software-specific steps?
- Does it include at least one practical example or decision table?
- Are links, headings, and timecodes valid?

Run `python scripts/validate_plan.py --help` before submitting changes. Keep `SKILL.md` under 500 lines and avoid duplicating detailed reference content there.
